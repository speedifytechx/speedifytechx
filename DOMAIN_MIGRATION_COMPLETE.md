#### If using Nginx
Add this to your nginx configuration:
```nginx

    listen 80;
    server_name speedifytechx.com www.speedifytechx.com;
    return 301 https://speedifytechx.in$request_uri;
}

server {
    listen 443 ssl;
    server_name speedifytechx.com www.speedifytechx.com;
    return 301 https://speedifytechx.in$request_uri;
}
```

## 🆘 Troubleshooting

### Issue: Old domain still shows in Google
**Solution:** 
- Be patient (can take 2-4 weeks)
- Verify 301 redirects are working
- Use "Change of Address" tool in Google Search Console
- Request indexing of new pages

### Issue: Traffic dropped after migration
**Solution:**
- Check that 301 redirects are working correctly
- Verify all pages are accessible
- Request re-indexing of important pages
- Give it 2-3 weeks to stabilize

### Issue: Pages not indexing
**Solution:**
- Check robots.txt isn't blocking pages
- Verify sitemap is submitted and processing
- Use URL Inspection tool to request indexing
- Check for noindex meta tags

### Issue: Verification codes not working
**Solution:**
- Ensure codes are in `<head>` section of ALL HTML pages
- Clear CDN cache if using one
- Wait a few hours and try again
- Try alternative verification method (DNS/file upload)
